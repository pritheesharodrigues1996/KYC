
# KYC Application

A KYC application to register customer KYC Information


## Prerequisites

 - Install Node JS
 - Install Mongodb
 - Install VSCode


## Installation

Install meeting application with npm

```bash
  npm install

```
    
## Environment Variables

To run this project, you will need to add the following environment variables to your .env file

`PORT`
`MONGODB_URI`
`SECRET_KEY`


## run the project

```bash
  npm start
```
